# 知识解压课程体系：入门大纲总索引

这套课程把“先跑通案例，再从机制展开概念”落实为 5 个板块、18 门子课程和 265 节入门课。总论见 [《知识解压：AI 时代学习方式的革命》](../overall.md)。

课程不要求学习者先掌握专业术语。每个大领域先压缩成一个足以生成所属课程的基础问题；这个问题不能只是其中一门课的典型场景。解压从最简单的回答开始，每增加一门课或一章，只加入一层新的现实条件、困难或边界。

进入具体课程后，仍从一个可观察的问题或案例出发，用少数关系解释事情怎样发生，再逐步展开概念、机制和练习。学习者完成一门课后，应该能够解释新案例、识别判断边界，而不只是记住一批名词。

## 课程共同结构

每门课都包含六个部分：

1. 核心问题：明确这门课试图解释什么。
2. 解压模型：用 1–2 句搭起全课骨架；先让读者看见一个熟悉现象或具体问题，再给出可检验的概括或强断言，不为追求简短牺牲共鸣和理解。解压模型不是缩短版目录：只保留能够生成全课的动作、循环或判断框架，章节变量留在“核心变量”中展开。
3. 核心变量：列出驱动该领域的 3–6 个要素。
4. 学习地图：先跑通案例，让概念在机制需要时出现，再换条件检验原有判断。
5. 逐课大纲：每节都写清本节回答的问题、关键概念和可观察的完成标志。
6. 结课项目与边界：用一个小项目检验模型，同时说明入门课暂时不处理什么。

单节课建议使用同一条教学链路：

```text
真实现象或问题
→ 具体案例
→ 运作机制
→ 可迁移规律
→ 小练习或判断题
```

## 五个板块的解压起点

| 板块 | 最基础的问题 |
|---|---|
| AI | 面对当前情况，机器凭什么决定下一步？ |
| 金融 | 人们怎样把资源交给别人或带到未来，并说清谁得到什么、谁承担损失？ |
| 艺术 | 怎样用线索，引导别人的注意、理解和行动？ |
| 人文 | 关于人和社会的说法，怎样才算站得住？ |
| 语言 | 人怎样用声音和文字，让别人重建自己脑中的意思？ |

这些问题不是板块广告，也不是一门子课程的代表题。每门所属课程都必须说明：它为基础问题增加了哪个新的现实条件；如果一门课无法从中自然生长，基础问题就还没有压到正确层级。

## 建议学习方式

不必按总表从头学到尾。选择一门此刻最需要的课程，先完成它的前三课；如果核心模型能够解释你原本觉得零散的现象，再继续完成整门课。

同一板块内可使用以下顺序：

- AI：机器学习 → 深度学习 → 大语言模型 → AI Agent。
- 金融：货币 → 支付系统 → 投资 → 金融机构。
- 艺术：音乐、美术和电影可独立开始；设计适合作为“从表达走向解决问题”的补充。
- 人文：心理学、哲学和历史可独立开始，再用另外两门课校正个人、观念与社会三个观察尺度。
- 语言：英语和中文可独立开始；写作可与任何一门课并行，用来检验自己是否真正形成了结构。

## 从大纲扩写成正式课程

后续扩写每一节时，应保留四个约束：

- 解压模型通常写 1–2 句：第一句连接读者熟悉的体验，第二句给出能够生成全课的规律；一句已经讲清时，不必硬凑两句。
- 一节只解决一个主要问题，不为追求完整度提前塞入进阶知识。
- 抽象规律必须由一个具体案例托住，并说明规律何时不适用。
- 练习必须迫使学习者使用本节模型做判断、解释或创作，不能只要求复述定义。

完成正式课程后，再做一次全局检查：所有章节能否回到解压模型；不能归入模型的内容，要么标为例外，要么修改模型，不能靠继续增加概念掩盖矛盾。
