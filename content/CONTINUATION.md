## 逐批流程

- [ ] 批次 0｜全课压缩：使用 `anthropic-skills:dean-distill` 通读全课材料，写出公理句、最小模型和可迁移规律；用 14 节大纲做归格测试，再用一个全新任务做生成器测试。失败时先改模型。
- [ ] 批次 1｜第 01–04 课：回答与行动、行动闭环、可验收目标、状态。重点检查零知识读者是否能从可观察变化进入模型。
- [ ] 批次 2｜第 05–07 课：计划、下一行动和工具接口。重点检查依赖顺序、输入输出与权限是否说清。
- [ ] 批次 3｜第 08–11 课：工具调用、记忆、反馈改道和重复操作。重点检查案例能否逐步复算，失败恢复是否会制造新副作用。
- [ ] 批次 4｜第 12–14 课：人工审批、固定工作流和多智能体。重点检查风险边界、角色交接与协调成本。
- [ ] 批次 5｜全课接入：创建课程入口与路由，更新生成脚本、状态文案、测试和文档，再运行完整验证。

每个正文批次都使用 `dean-writing-standards`。一批结束时先检查该批每课是否包含可观察现象、1–2 句核心断言、机制、可复核案例、迁移任务、边界、术语短释和可观察完成标志，再勾选批次。

## 完成定义

AI Agent 只有同时满足以下条件才算完整教程：

1. 14 节都符合 `Lesson` 数据结构，没有占位句，也没有把大纲扩写成空泛正文。
2. 14 节都能归入全课最小模型；新任务可以用该模型生成行动与检查路径。
3. 每课的案例、数字、行动方向和停止条件可复核；每课都有要求读者实际使用模型的练习与检查项。
4. 正式总览页、14 个章节页、上一门课的继续学习链接和 AI 课程地图都能访问。
5. 目录显示 4 门完整教程、59 节正文和 14 门、206 章大纲；全站总数仍是 5、18、265。
6. `npm run catalog:generate`、`npm run lint` 和 `npm test` 全部通过。
7. README 和本文件在同一批改动中更新，最后交接记录说明验证结果和下一步。
